# Municipal ward boundaries

Used to tag each river stretch with its municipal corporation and ward. Not fetched
automatically: these change only when wards are redrawn.

| File | What | Source | License |
|---|---|---|---|
| `pmc-wards-2022.geojson` | Pune Municipal Corporation electoral wards (prabhag), 2022 | [DataMeet Municipal_Spatial_Data](https://github.com/datameet/Municipal_Spatial_Data/tree/master/Pune), traced from PMC's 2022 ward maps by SeerMaps for Nikhil VJ ([answerquest/pune-2022-wards](https://github.com/answerquest/pune-2022-wards)) | MIT |
| `pcmc-wards.geojson` | Pimpri-Chinchwad Municipal Corporation electoral wards | [DataMeet Municipal_Spatial_Data](https://github.com/datameet/Municipal_Spatial_Data/tree/master/PCMC), scraped from Shelter Associates | CC BY-SA 2.5 India |

Both are community-traced and may be slightly off at the edges; the PCMC file predates
the latest ward delimitation.
